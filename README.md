What is SafeLine?
SafeLine is a smart content moderation pipeline that checks text in three stages — Toxicity, Sentiment, and Final Verdict — to decide if a piece of content is safe to publish, needs review, or should be blocked.

Why SafeLine?
Every day, millions of posts, comments, and messages are shared online. Manually checking each one is impossible. SafeLine automates this with a clean, visual AI pipeline that analyzes text in seconds and gives a clear decision.

How it works
Paste text — Drop any comment, review, or message into the input box.
Run the pipeline — Watch the rainbow data flow through three animated stages.
Get the verdict — See the toxicity score, sentiment, and final decision instantly.
